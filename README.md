# P&O3 University project

## Description
Our project was a devie that measured data of the user and helped them monitor their health.
This repository contains the code needed for our P&O3 project. It is a website (still on localhost) that displays measured data like heartbeat, oxygen saturation and is 
able to notify when the device detects a fall. The backend also contains the code used to process the incoming signals.

## Overview
This website was made with Python Django. All backend is writtend in python, while the front-end exists of several HTML pages. Incoming signals are received with the help of websockets.
